== Abstract

*SECURITY CLASSIFICATION: NATO RESTRICTED (NR) (NATO)*

This document defines the NWP Radar Profile, an OGC API - Environmental Data Retrieval (EDR) Part 3 Service Profile. It specifies normative requirements and conformance tests for server implementations conforming to this profile.

[[req_nwp_radar_spatial_extents_crs]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/spatial-extents-crs
statement:: The coordinates for the bounding box SHALL be defined in the CRS EPSG:4326 (WGS84) with geographical latitude, then longitude, in decimal degrees.
part:: The service bbox SHALL have a geometry defined in WGS84.
part:: The service bounding box coordinates SHALL be returned with geographical latitude, then longitude.
part:: The service bounding box coordinates SHALL be returned in decimal degrees.
====
[[req_nwp_radar_profile_bbox_coordinates]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-bbox-coordinates
statement:: The coordinates for the 2D bounding box SHALL be defined in the CRS84 EPSG:4326 (WGS84) for the extent [-180, -90, 180, 90].
part:: The 2D bounding box boundary SHALL be for the extent [-180, -90, 180, 90].
part:: The coordinate reference system for the bounding box SHALL be EPSG:4326 (WGS84).
====
[[req_nwp_radar_profile_trs_values]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-trs-values
statement:: Temporal Reference System (trs) values SHALL be presented in Gregorian calendar Zulu datetime (UTC) in 24 hour clock with a precision to the second according to the time format specified in RFC 3339.
part:: The service trs SHALL be in Gregorian calendar Zulu datetime (UTC) in 24 hour clock with a precision to the second.
part:: The service trs SHALL be the time format specified in RFC 3339.
====
[[req_nwp_radar_profile_vrs_values]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-vrs-values
statement:: Vertical Reference System (vrs) values SHALL be height in metres.
part:: The service vrs SHALL be in height metres.
part:: The service vrs SHALL be EPSG:3855.
part:: The service vrs SHALL use the vertical datum EGM2008 geoid as the zero-height reference (orthometric height relative to mean sea level).
====
[[req_nwp_radar_profile_keywords]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-keywords
statement:: The following keywords SHALL be included in the collection response: "cube", "radius", "items", "precipitation_amount", "radar".
part:: The collection keywords array SHALL include "cube", "radius", and "items".
part:: The collection keywords array SHALL include "precipitation_amount" and "radar".
====
[[req_nwp_radar_profile_links]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-links
statement:: All links objects SHALL have href, rel, title and type attributes.
part:: Each link object SHALL include a non-empty href attribute.
part:: Each link object SHALL include rel, title and type attributes.
====
[[req_nwp_radar_profile_query_types]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/profile-query-types
statement:: The following data queries SHALL be supported: "cube", "items", "radius".
part:: The collection SHALL advertise cube, items and radius data queries.
====
[[req_nwp_radar_items_endpoint]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_radar/items-endpoint
statement:: The service SHALL provide a /collections/nwp_radar_precipitation/items endpoint.
part:: The service SHALL return CoverageJSON FeatureCollection and GRIB2, GeoTIFF, HDF5, NetCDF4, PNG file formats.
part:: The service SHALL return a default file format of GeoTIFF.
part:: Each feature SHALL include precipitation_amount property.
part:: Each feature SHALL include datetime property in the format YYYY-MM-DDTHH:MM:SSZ e.g. 2026-04-12T21:20:50.52Z.
part:: The items data queries SHALL return CoverageJSON that complies with the OGC CoverageJSON standard - link:++https://docs.ogc.org/cs/21-069r2/21-069r2.html#_df6ce66a-7369-49cb-b59f-47a8c5d424ca++[]
part:: The items data queries SHALL return GeoTIFF which complies with the DGIWG 108 GeoTIFF for GeoRef Imagery Standard.
part:: The items data queries SHALL return GRIB2 which complies with the WMO Manual On Codes - link:++https://library.wmo.int/records/item/35625-manual-on-codes-volume-i-2-international-codes++[].
part:: The items data queries SHALL return HDF5 which complies with the CF-NetCDF v1.13 conventions - link:++https://cfconventions.org/Data/cf-conventions/cf-conventions-1.13/cf-conventions.html++[].
part:: The items data queries SHALL return NetCDF4 which complies with the CF-NetCDF v1.13 conventions - link:++https://cfconventions.org/Data/cf-conventions/cf-conventions-1.13/cf-conventions.html++[].
====
