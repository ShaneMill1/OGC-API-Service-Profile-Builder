== Abstract

This document defines the MetOcean Profile for OGC API - EDR, an OGC API - Environmental Data Retrieval (EDR) Part 3 Service Profile. It specifies normative requirements and conformance tests for server implementations conforming to this profile.

== Scope

This standard defines the MetOcean Profile for OGC API - EDR. It specifies requirements and conformance tests for implementations of this profile.

== Conformance

Conformance with this standard shall be checked using the Abstract Test Suite in Annex A.

The following conformance classes are defined:

* link:++http://www.opengis.net/spec/profile/metocean-ogcapi-environmental-data-retrieval/1.0/conf/core++[]

[[req_core_core_openapi]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-openapi
statement:: An API definition SHALL be described using an OpenAPI 3.1 document.
part:: The API definition SHALL be described using an OpenAPI document (version 3.1 or higher).
part:: The OpenAPI document SHALL be encoded as one of the OpenAPI JSON/YAML media types.
part:: The landing page SHALL link the OpenAPI document with rel=service-desc.
part:: The landing page SHALL link API documentation with rel=service-doc and type text/html.
====
[[req_core_core_collection_identifier]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-identifier
statement:: A collection identifier SHALL NOT convey structured metadata and SHOULD use the fixed value list.
part:: A collection identifier SHALL NOT be used to convey structured metadata.
part:: A collection identifier SHOULD use one of insitu-observations, climate_data, radar_observations, weather_warnings, weather_forecast.
part:: The identifier string MAY include a postfix to the listed values if needed.
====
[[req_core_core_collection_title]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-title
statement:: A title SHALL be set for all collections and SHALL NOT exceed 50 characters.
part:: A title SHALL be set for all collections.
part:: A title SHALL NOT have more than 50 characters.
part:: A title SHOULD be written in English.
part:: A title SHOULD place the most important information first to guard against truncation.
part:: A title SHOULD describe the collection understandably for non-experts (topic/domain and geographical area).
====
[[req_core_core_collection_license]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-license
statement:: A collection SHALL link to a license of its data with rel=license and type=text/html.
part:: The links property in a collection SHALL contain a link to a license of its data.
part:: The license link SHALL set the rel property to license.
part:: The type property SHALL be set to text/html.
part:: If the data is open data, the license SHALL be CC BY 4.0 with href link:++https://creativecommons.org/licenses/by/4.0/++[].
====
[[req_core_core_collection_spatial_extent]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-spatial-extent
statement:: The collection spatial extent and CRS list SHALL use OGC:CRS84.
part:: The value of extent.spatial.crs SHALL be OGC:CRS84.
part:: The value of crs SHALL include the element OGC:CRS84.
part:: If crs_details is specified for a data_queries object, it SHALL include an object whose crs value is OGC:CRS84.
part:: Additional CRSs SHOULD be presented as EPSG:<code> in crs and data_queries.*.crs_details.crs.
====
[[req_core_core_collection_temporal_extent]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-temporal-extent
statement:: The value of extent.temporal.trs SHALL be Gregorian.
part:: The value of extent.temporal.trs SHALL be Gregorian.
====
[[req_core_core_collection_parameter_names]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-parameter-names
statement:: Parameter objects SHALL specify label, description and unit using the profile conventions.
part:: The keys in parameter_names and id in the parameter object SHALL NOT convey structured metadata.
part:: A parameter object SHALL specify the fields label, description and unit.
part:: label SHALL NOT have more than 50 characters.
part:: label SHALL be written in English.
part:: unit SHALL use QUDT; unit.symbol.type SHALL be link:++https://qudt.org/vocab/unit/<unit>++[] and unit.symbol.value the qudt symbol.
part:: observedProperty SHALL use the CF-convention (observedProperty.id = link:++https://vocab.nerc.ac.uk/standard_name/<name>++[]) when available; otherwise use observedProperty.description.
====
[[req_core_core_collection_radius_data_query]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-collection-radius-data-query
statement:: A radius data query within_units array SHALL contain m (SI unit of length).
part:: The within_units array in a variables object for a radius data query SHALL contain m.
part:: within_units MAY contain more values, each defined as a unit at link:++https://qudt.org++[] using the unit symbol.
part:: A radius query with a limit parameter SHOULD return the closest items to the radius centre.
====
[[req_core_core_locations_query_response_format]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-locations-query-response-format
statement:: A /locations response SHALL be a GeoJSON FeatureCollection with id and properties.name per feature.
part:: The /locations response SHALL be a GeoJSON document with a FeatureCollection object.
part:: Each Feature SHALL have id of type string and properties.name of type string.
part:: If not all collection parameters are provided, properties.parameter-name SHALL list a subset of the parameter_names keys.
part:: Links with more information SHALL be included in properties.links as OGC API - Common link objects.
part:: A more detailed description MAY be provided via properties.description.
part:: All strings SHALL be in English.
====
[[req_core_core_error_handling]]
[requirement]
====
[%metadata]
identifier:: /req/core/core-error-handling
statement:: Empty results SHALL return HTTP 204 and 4xx responses SHOULD comply with RFC 9457.
part:: A query for data inside the extent that results in no data SHALL return HTTP 204 with no content.
part:: A query partially within the extent SHALL respond as within the extent, returning only the in-extent portion.
part:: Any 4xx response SHOULD comply with RFC 9457 Problem Details for HTTP APIs.
====

====
[[req_insitu_observations_insitu_collection_parameter_names]]
[requirement]
====
[%metadata]
identifier:: /req/insitu-observations/insitu-collection-parameter-names
statement:: Insitu parameters SHALL specify metocean:standard_name, metocean:level and measurementType.
part:: Each parameter SHALL specify metocean:standard_name set to a value from the standard_name custom dimension.
part:: Each parameter SHALL specify metocean:level set to a value from the level custom dimension.

[[req_insitu_observations_insitu_collection_custom_dimensions]]
[requirement]
====
[%metadata]
identifier:: /req/insitu-observations/insitu-collection-custom-dimensions
statement:: An insitu-observations collection SHALL define standard_name and level custom dimensions.
part:: The collection SHALL have an extent.custom object with id standard_name.
part:: Custom dimension standard_name SHALL list CF standard names in values.
part:: Custom dimension standard_name SHALL specify reference link:++https://vocab.nerc.ac.uk/standard_name/++[].
part:: The collection SHALL have an extent.custom object with id level.
part:: Custom dimension level SHALL specify reference "Height of measurement above ground level in meters".
====

[requirement]
====
[%metadata]
identifier:: /req/insitu-observations/insitu-coveragejson-parameters
statement:: CoverageJSON parameters SHALL carry metocean:measurementType, metocean:standard_name and metocean:level.
part:: Each object in parameters in a coverage SHALL have metocean:measurementType with the same properties as measurementType.
part:: Each object in parameters SHALL have metocean:standard_name.
part:: Each object in parameters SHALL have metocean:level.
====

[[req_nwp_nwp_collection_parameter_names]]
[requirement]
====
[%metadata]
identifier:: /req/nwp/nwp-collection-parameter-names
statement:: NWP parameters SHALL use ECMWF short names per Annex D for id and description.
part:: WIPPS Manual Global Deterministic NWP parameters SHALL be provided using ECMWF short names per Annex D.
part:: The parameter name SHALL be provided in the description property.
part:: The ECMWF short name SHALL be provided in the id property.
====
[[req_nwp_nwp_collection_granularity]]
[requirement]
====
[%metadata]
identifier:: /req/nwp/nwp-collection-granularity
statement:: An NWP collection represents a model; instances represent model runs identified by RFC3339 datestamps.
part:: A collection SHALL represent and describe a model.
part:: A collection instance SHALL represent and describe a model run.
part:: A collection instance identifier SHALL be represented by an RFC3339 datestamp.
part:: A collection temporal instance or interval SHALL represent a timestep or timesteps of a model run.
====
[[req_nwp_nwp_collection_data_queries]]
[requirement]
====
[%metadata]
identifier:: /req/nwp/nwp-collection-data-queries
statement:: An NWP collection SHALL support position and cube; no instance means latest.
part:: A collection SHALL support position and cube queries.
part:: Data queries without an instance SHALL be interpreted as the latest instance of a collection.
part:: A datetime parameter between two timestamps SHALL trigger an HTTP 400 Bad Request.
====
