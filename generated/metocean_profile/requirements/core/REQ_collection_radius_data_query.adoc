[[req_core_collection_radius_data_query]]
[requirement]
====
[%metadata]
identifier:: /req/core/collection_radius_data_query
part:: The within_units array in a variables object for a radius data query SHALL contain m.
part:: within_units MAY contain more values, each defined as a unit at https://qudt.org using the unit symbol.
part:: A radius query with a limit parameter SHOULD return the closest items to the radius centre.
====
