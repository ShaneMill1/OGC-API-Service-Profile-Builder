[[req_nws_connect_pubsub_websocket]]
[requirement]
====
[%metadata]
identifier:: /req/nws_connect/pubsub-websocket
statement:: The service SHALL support a native WebSocket pub/sub endpoint for browser clients.
part:: The service SHALL provide a WebSocket endpoint at /ws for local development (ws) and production (wss).
part:: The WebSocket endpoint SHALL deliver the same GeoJSON feature notifications as the AMQP 1.0 and MQTT transports.
part:: WebSocket connections SHALL authenticate with the same identity used for the AMQP/MQTT transports.
====
