[[ats_nws_connect_pubsub_amqp]]
[abstract_test]
====
[%metadata]
identifier:: /conf/nws_connect/pubsub-amqp
target:: /req/nws_connect/pubsub-amqp
test-purpose:: Validate that pubsub amqp is correctly implemented.
test-method::
step:: Connect to the AMQP 1.0 broker (edr-broker) on port 5672 using SASL PLAIN (email + wsk_ key).
step:: Declare a queue and bind it to the amq.topic exchange with binding key collections.water_gauge.items.
step:: Verify notifications are received as GeoJSON features.
step:: Bind a queue to amq.topic with binding key collections.wwa.items.
step:: Verify notifications are received as GeoJSON features.
step:: Connect to the MQTT broker (edr-broker) on port 1883 and subscribe to topic collections/+/items.
step:: Verify notifications are received as GeoJSON features.
====
