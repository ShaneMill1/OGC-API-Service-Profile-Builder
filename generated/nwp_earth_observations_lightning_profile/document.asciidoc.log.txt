== Abstract

This document defines the DGIWG NWP Earth Observations Lightning Profile, an OGC API - Environmental Data Retrieval (EDR) Part 3 Service Profile. It specifies normative requirements and conformance tests for server implementations conforming to this profile.

== Scope

This standard defines the DGIWG NWP Earth Observations Lightning Profile. It specifies requirements and conformance tests for implementations of this profile.

== Conformance

Conformance with this standard shall be checked using the Abstract Test Suite in Annex A.

The following conformance classes are defined:

[[req_nwp_earth_observations_lightning_items_endpoint]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_earth_observations_lightning/items-endpoint
statement:: The service SHALL provide a /collections/earth_observations_lightning/items endpoint.
part:: The service SHALL return GeoJSON FeatureCollection.
part:: Each feature SHALL include frequency_of_lightning_flashes_per_unit_area property.
part:: Each feature SHALL include datetime property in the format YYYY-MM-DDTHH:MM:SSZ e.g. 2026-04-12T21:20:50.52Z.
====
[[req_nwp_earth_observations_lightning_cube_endpoint]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_earth_observations_lightning/cube-endpoint
statement:: The service SHALL provide a /collections/earth_observations_lightning/cube endpoint.
part:: The service SHALL return CoverageJSON FeatureCollection.
part:: Each feature SHALL include frequency_of_lightning_flashes_per_unit_area property.
part:: Each feature SHALL include datetime property in the format YYYY-MM-DDTHH:MM:SSZ e.g. 2026-04-12T21:20:50.52Z.
====
[[req_nwp_earth_observations_lightning_radius_endpoint]]
[requirement]
====
[%metadata]
identifier:: /req/nwp_earth_observations_lightning/radius-endpoint
statement:: The service SHALL provide a /collections/earth_observations_lightning/radius endpoint.
part:: The service SHALL return CoverageJSON FeatureCollection.
part:: Each feature SHALL include frequency_of_lightning_flashes_per_unit_area property.
part:: Each feature SHALL include datetime property in the format YYYY-MM-DDTHH:MM:SSZ e.g. 2026-04-12T21:20:50.52Z.
====

== Abstract Test Suite

[conformance_class]
====
[%metadata]

abstract-test:: /conf/nwp_earth_observations_lightning/items-endpoint
abstract-test:: /conf/nwp_earth_observations_lightning/cube-endpoint
abstract-test:: /conf/nwp_earth_observations_lightning/radius-endpoint
====

[[ats_nwp_earth_observations_lightning_items_endpoint]]
[abstract_test]
====
[%metadata]
identifier:: /conf/nwp_earth_observations_lightning/items-endpoint
target:: /req/nwp_earth_observations_lightning/items-endpoint
test-purpose:: Validate that items endpoint is correctly implemented.
test-method::
step:: Send GET request to /collections/earth_observations_lightning/items.
step:: Verify response Content-Type is application/json.
step:: Verify each feature contains frequency_of_lightning_flashes_per_unit_area property.
step:: Verify each feature contains datetime property.
====
[[ats_nwp_earth_observations_lightning_cube_endpoint]]
[abstract_test]
====
[%metadata]
identifier:: /conf/nwp_earth_observations_lightning/cube-endpoint
target:: /req/nwp_earth_observations_lightning/cube-endpoint
test-purpose:: Validate that cube endpoint is correctly implemented.
test-method::
step:: Send GET request to /collections/earth_observations_lightning/cube with a valid coordinate in crs_4326 and a radius of 1km.
step:: Verify response Content-Type is application/json.
step:: Verify each feature contains frequency_of_lightning_flashes_per_unit_area property.
step:: Verify each feature contains datetime property.
step:: Verify each feature is in projection crs_4326.
====
[[ats_nwp_earth_observations_lightning_radius_endpoint]]
[abstract_test]
====
[%metadata]
identifier:: /conf/nwp_earth_observations_lightning/radius-endpoint
target:: /req/nwp_earth_observations_lightning/radius-endpoint
test-purpose:: Validate that radius endpoint is correctly implemented.
test-method::
step:: Send GET request to /collections/earth_observations_lightning/radius with a valid coordinate in crs_4326.
step:: Verify response Content-Type is application/json.
step:: Verify each feature contains frequency_of_lightning_flashes_per_unit_area property.
step:: Verify each feature contains datetime property.
step:: Verify each feature is in projection crs_4326.
step:: Verify each feature is returned within the radius area.
====
